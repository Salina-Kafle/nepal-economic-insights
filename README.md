# Nepal Economic Insights
## About this project
Nepal Economic Insights is an independent research portfolio project exploring Nepal's economic growth, inflation, and dependence on remittances using publicly available data.
The project aims to turn economic data into clear findings that can support development discussions, programme planning, and evidence-based decision-making.
## Research questions
- How has Nepal's economic growth changed over time?
- How have inflation trends evolved?
- How important are remittances to Nepal's economy?
- What do these trends suggest for Nepal's development priorities?
## Data sources
The analysis will use publicly available data from the World Bank and, where relevant, Nepal Rastra Bank.
## Planned outputs
- A structured economic dataset in Excel
- Charts showing key economic trends
- A short research brief summarising the findings and their development implications
## Methodology
Data sources, indicator definitions, years covered, and any limitations will be documented transparently. Missing data will not be treated as zero.
## Project status
In progress — data collection and analysis are planned as the next steps.
